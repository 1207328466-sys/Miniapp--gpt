## 不能丢的约定

1. **每个用例末尾的 `.catch(e => process.exit(1))` 不能删** —— 删了用例永远通过
   （退出码 3 = 前置条件不满足，会被 conftest 转成 SKIPPED，也是约定的一部分）
2. **步骤函数必须 `return page`**；`runAppSteps` 靠 `func.name` 打日志与命名截图
3. **点击/滑动一律走 `tapElement` / `swipeUp`**（真实 adb 事件）；合成 `.click()` 在小程序上无效且会误报
4. **答题活动状态在 0/1 与 1/1 之间来回变**，且本框架从未提交 —— 疑为人工操作。
   在查清之前，"点选项"也按"可能写数据"对待（`ALLOW_INTERACT` 默认 false）
5. **测试/生产是两个不同的小程序**：设 `UITEST_APP_ID` 打开安全阀；
   生产 appid 仍待 owner 补充（`knowledge/环境与目标小程序.md`）
6. **同一部手机可能被别的 AI / 别人操作**：动手前截图确认现场，偶发失败先怀疑环境
