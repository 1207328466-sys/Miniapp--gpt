16. **写操作的开关只能是环境变量**（`UITEST_ALLOW_SUBMIT=1`），不许写在代码里、不许默认打开：
    同一份用例，跑的人不同、场景不同，"要不要写数据"就该由**跑的人**决定。
    没开关时**报错或跳过，绝不静默执行** —— 这条由 `scripts/check-safety.py` 逐条盯住
17. **表格里填错的行，只让它自己红**：`tools/export_cases.py` 把"能归到某条用例"的错误记在
    那条用例身上（`errors`），真机跑时只有它失败、别的照跑。归不到用例的（整行没编号 / 表头被改 /
    空表）才整表停下 —— 那种情况"跑出来的结果"整体不可信
18. **写操作的表格动作：开关没开时记「跳过」，不是记「红」**（`writeSwitchOffError` 会带上
    `preconditionNotMet`）。理由：默认全量跑里长期挂着一条红的"写用例"，久而久之就没人看红了。
    跳过是**可见的**：报告里写原因，摘要里单独列一行"跳过的 = 这次没测"
19. **写数据的一条龙动作必须自带复位**（如「复制当前案例」：记水位 → 复制 → 断言 → 库里校验 → 自动复位）。
    拆成多步给人"忘记写最后一步"的机会，而忘记复位的后果是别人看到数据被改过
20. **「回到首页」必须让前台页真的变成首页信息流**（坑 28）：跨页查找只能用于"定位"，
    到达判断一律看**前台页** —— 否则会出现"这一步报成功、下一步失败"的假成功
