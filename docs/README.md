## 三、三条读文档的约定

1. **结论在前、细节在后**：每节先给结论或判据，再讲过程 —— 赶时间看前两行就够。
2. **数字以代码为准**：用例数、动作数、闸门数这类数字由离线检查盯着（`python scripts/verify-all.py`），
   过期的会报红；没被盯住的文档改完请顺手核一遍，别让它悄悄过期。
3. **踩坑记录先看索引**：按症状分成五类（跑不起来 / 点了没反应 / 断言不对 / 动数据之前 / 表格与工具自己出的错），
   找不到再从头翻。
