## 三条读文档的约定

1. **结论在前、细节在后**：每节先给结论或判据，再讲过程 —— 赶时间看前两行就够。
2. **数字要能对得上**：用例数、动作数、行号这类数字由离线闸门查（`python scripts/verify-all.py`），过期的会报红。
3. **踩坑记录先看索引**：按症状分成四类（跑不起来 / 点了没反应 / 断言不对 / 动数据之前），找不到再从头翻。
