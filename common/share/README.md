# 公共模块 common-module

common-module 是 Test 项目的公共模块，提供日志管理、配置管理等核心基础功能，旨在提升代码复用性和项目维护性，降低重复开发成本。

## 目录

```
common-module/
├── __init__.py          # 模块导出文件，暴露核心可调用接口
├── base_log.py          # 日志管理基础类实现
├── base_config.py       # 配置管理基础类实现
├── sc_log.py            # 日志业务类（继承BaseSCLog，对外提供日志能力）
├── sc_config.py         # 配置业务类（继承BaseSCConfig，对外提供配置能力）
├── test_common.py       # 通用测试方法（init_global、web_test）
├── README.md            # 模块说明文档
└── .gitignore           # Git版本控制忽略文件配置
```

## 核心功能

### 1. 日志管理（BaseSCLog）

base_log.py 中实现的 BaseSCLog 是日志管理的基础类，为项目提供标准化的日志输出能力，核心特性：

单例模式：全局唯一日志实例，避免重复初始化日志服务

多端输出：同时支持控制台（StreamHandler）和文件（TimedRotatingFileHandler）双端日志输出

日志轮转：按天自动轮转日志文件，默认保留 7 天历史日志，避免日志文件体积过大

编码兼容：日志文件采用 UTF-8 编码，解决中文日志乱码问题

丰富格式：日志格式包含时间、日志名称、级别、文件路径+行号、日志消息，便于问题定位

### 2. 配置管理（BaseSCConfig）

base_config.py 中实现的 BaseSCConfig 是配置管理的基础类，提供高效、灵活的配置加载能力，核心特性：

单例模式：全局唯一配置实例，确保配置数据一致性

懒加载机制：初始化时不立即加载配置，首次访问配置时才读取文件，提升项目启动效率

热重载能力：自动检测配置文件修改时间，配置更新时自动重新加载，无需重启服务

多配置支持：支持主配置文件和模型配置文件的独立加载与管理

YAML 解析：基于 PyYAML 解析配置文件，支持灵活的层级化配置格式
